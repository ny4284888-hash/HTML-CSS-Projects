# Assignment 7: About Me Page

## Aim
To build a short About Me webpage using semantic HTML tags, an about section and a contact link.

## Theory

### 1. Header
The `<header>` tag defines the introductory section of a webpage.

### 2. Navigation
The `<nav>` tag contains navigation links.

### 3. Main
The `<main>` tag contains the main content of a webpage.

### 4. Section
The `<section>` tag groups related content.

### 5. Footer
The `<footer>` tag defines the bottom section of a webpage.

### 6. Mailto Link
The `mailto:` attribute opens the default email application.

## Tasks Completed

2. Added an About Me section inside main.
3. Added a contact email link inside footer.
