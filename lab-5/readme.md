# Assignment 5: Links and Images

## Aim
To link two HTML pages together and add an image with alternative text.

## Theory

### 1. Anchor Tag
The `<a>` tag is used to create hyperlinks in HTML.

Example:
`<a href="nandaniresume.html">resume</a>`

### 2. href Attribute
The href attribute specifies the destination of a link.

### 3. Image Tag
The `<img>` tag is used to display images on a webpage.

### 4. Image Attributes
- src: Specifies the image path.
- alt: Provides alternative text for the image.
- width: Sets image width.
- height: Sets image height.
