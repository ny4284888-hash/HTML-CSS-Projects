# Assignment 12: Box Model, Cards and Scrolling

## 1. Aim
To understand CSS box sizing, create a styled card and make a box scrollable using CSS overflow.

## 2. Topics Covered
- CSS Box Model
- `box-sizing: content-box`
- `box-sizing: border-box`
- CSS Cards
- Border and Border Radius
- Padding
- CSS Overflow
- Scrolling

## 3. Tasks Performed

### Task 1: Box Model
**File:** `programs/box-model.html`
- Created two boxes with 200px width, 20px padding and 5px border.
- Used `content-box` and `border-box`.
- Compared their total widths.

### Task 2: CSS Card
**File:** `programs/card.html`
- Created a card using a div element.
- Added background colour and 2px border.
- Used 12px border radius and 16px padding.
- Added a heading and paragraph.

### Task 3: CSS Scrolling
**File:** `programs/scroll.html`
- Created a box with 120px fixed height.
- Used `overflow: auto`.
- Added five lines of text.
