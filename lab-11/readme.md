# Assignment 11: Units and CSS Variables

## 1. Aim
To understand CSS units and use CSS variables to store and reuse colours, font sizes, and spacing.

## 2. Topics Covered
- CSS units: px, %, rem
- CSS variables
- `:root` selector
- `var()` function
- External CSS file linking

## 3. Tasks Performed

### Task 1: CSS Units
**File:** `program/units.html`
- Created a 200px wide and 40px high box.
- Created a 50% wide and 40px high box.
- Used 1.5rem font size for a paragraph.

### Task 2: CSS Variables
**File:** `program/variables.html`
- Defined main colour, accent colour, and page padding.
- Used CSS variables with the `var()` function.
- Applied colours and spacing to webpage elements.

### Task 3: CSS Design Tokens
**Files:** `program/tokens.html`, `program/tokens.css`
- Defined primary colour, accent colour, heading size, and spacing.
- Linked an external CSS file to an HTML page.
- Applied variables to the body and heading.
