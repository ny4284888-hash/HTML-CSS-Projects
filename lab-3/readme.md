# Assignment 3: Your First HTML Page

## 1. Aim
To create basic HTML pages using headings, paragraphs, and text formatting tags.

## 2. Introduction to HTML

HTML stands for **HyperText Markup Language**.

- HTML is used to create web pages.
- It defines the structure of a webpage.
- HTML uses tags to display content in a browser.
- HTML is a markup language, not a programming language.

## 3. Basic Structure of HTML

```html
<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>This is my first webpage.</p>
</body>
</html>
```

### Explanation of HTML Tags

| Tag | Description |
|---|---|
| `<!DOCTYPE html>` | Declares HTML5 document |
| `<html>` | Root element of HTML |
| `<head>` | Contains page information |
| `<title>` | Sets browser tab title |
| `<body>` | Contains visible webpage content |
| `<h1>` | Main heading |
| `<p>` | Paragraph |

## 4. HTML Headings

HTML provides six heading levels, from H1 to H6.

```html
<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<h3>Third Heading</h3>
<h4>Fourth Heading</h4>
<h5>Fifth Heading</h5>
<h6>Smallest Heading</h6>
```

- `<h1>` is the highest-level heading.
- `<h6>` is the lowest-level heading.
- Headings help organize webpage content.

## 5. HTML Paragraph

The `<p>` tag is used to write paragraphs.

**Example:**

```html
<p>HTML is used to create web pages.</p>
<p>It provides structure to a website.</p>
```

Each paragraph is displayed as a separate block.

## 6. HTML Text Formatting Tags

| Tag | Use |
|---|---|
| `<strong>` | Shows important text, usually bold |
| `<em>` | Emphasizes text, usually italic |
| `<b>` | Makes text bold |
| `<i>` | Makes text italic |
| <u>

Underlines text

<br>

Inserts a line break

Example:

<p>This is <strong>important</strong> text.</p>
<p>This is <em>emphasized</em> text.</p>
<p>Hello<br>Welcome to HTML.</p>

7. HTML Tags and Elements

Tag: An HTML keyword written inside angle brackets, such as <p>.

Element: Complete structure containing opening tag, content and closing tag.

Example:

<p>Hello World</p>

<p> = Opening tag

Hello World = Content

</p> = Closing tag

8. Important Terms

Webpage: A document displayed in a web browser.

Browser: Software used to open websites, such as Chrome.

HTML Document: A file containing HTML code.

Live Server: VS Code extension used to open and preview webpages locally.
