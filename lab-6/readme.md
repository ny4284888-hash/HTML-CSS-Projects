# Assignment 6: Types of HTML Lists

## Aim
To create different types of HTML lists using unordered, ordered, nested and description lists.

## Theory

### 1. Unordered List
The `<ul>` tag creates a bulleted list.
The `<li>` tag defines each list item.

### 2. Ordered List
The `<ol>` tag creates a numbered list.
The `<li>` tag defines each list item.

### 3. Nested List
A nested list is a list placed inside another list item.

### 4. Description List
- `<dl>` defines a description list.
- `<dt>` defines a term or question.
- `<dd>` provides its description or answer.
