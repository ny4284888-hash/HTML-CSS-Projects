# Assignment 13: Flexbox Layouts

## 1. Aim
To create navigation bars, centred cards and wrapping card layouts using CSS Flexbox.

## 2. Topics Covered
- CSS Flexbox
- `display: flex`
- `justify-content`
- `align-items`
- `flex-wrap`
- `gap`

## 3. Tasks Performed

### Task 1: Navigation Bar
**File:** `programs/nav-flex.html`
- Created a horizontal navigation bar.
- Added Home, About, Events and Contact links.
- Used Flexbox to arrange links in one row.
- Applied a dark background and white text.

### Task 2: Centred Cards
**File:** `programs/centred-cards.html`
- Created three cards: Starter, Standard and Premium.
- Added prices ₹199, ₹349 and ₹499.
- Used `justify-content` and `align-items` to centre the cards.

### Task 3: Wrapping Cards
**File:** `programs/wrapping-cards.html`
- Created a Stationery Shop heading.
- Added Notebook, Pen, Bag and Book cards.
- Used `flex-wrap: wrap` to move cards onto new rows when space is limited.
