# Lab 1 – Theory

## 1. What is Git?
Git is a version control system used to track changes in files and manage project history.

## 2. What is a Git Repository?
A Git repository is a location where Git stores project files and their version history.

## 3. Git Initialization
The `git init` command initializes a new Git repository.

## 4. Git Configuration
Git username and email can be configured using:

```bash
git config --local user.name "Your Name"
git config --local user.email "your@email.com"
```

## 5. Git Status
The `git status` command shows the current state of files in the repository.

## 6. Git Add
The `git add` command stages changes before committing.

## 7. Git Commit
The `git commit` command saves staged changes with a message.

## 8. Git Log
The `git log --oneline` command displays commit history in a short format.

## Important Commands

| Command | Purpose |
|---|---|
| `git init` | Initialize repository |
| `git status` | Check file status |
| `git add` | Stage changes |
| `git commit -m "message"` | Save changes |
| `git log --oneline` | View commit history |
| `git config --local user.name` | Check username |
| `git config --local user.email` | Check email |

## Conclusion
Learned basic Git commands and understood how to track and save changes in a repository.
