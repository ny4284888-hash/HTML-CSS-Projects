# Lab 15: Responsive Pages with Media Queries

## 1. Aim
To create responsive web pages using CSS media queries.

## 2. Topics Covered
- Responsive Web Design
- Mobile-First Design
- CSS Media Queries
- Flexbox
- Responsive Images
- Responsive Font Sizes

## 3. Tasks Performed

### Task 1: Mobile First Layout
**File:** `programs/mobile-first.html`

- Created two cards using HTML.
- Displayed cards vertically on small screens.
- Displayed cards side by side on screens of 600px or wider.

### Task 2: Responsive Image
**File:** `programs/responsive-image.html`

- Added an image to the webpage.
- Used `max-width: 100%` and `height: auto`.
- Made the image adjust to the available screen width.

### Task 3: Responsive Text
**File:** `programs/responsive-text.html`

- Used `1rem` font size for the body.
- Set the heading to `1.5rem` on small screens.
- Changed the heading to `2.5rem` at 600px or wider.

## 4. Important CSS Properties

| Property | Use |
|---|---|
| `max-width` | Controls the maximum width |
| `height: auto` | Maintains image proportions |
| `flex-direction` | Controls the direction of flex items |
| `@media` | Applies styles based on screen size |
| `rem` | Sets font size relative to the root element |
