# Assignment 14: CSS Grid Layouts

## 1. Aim
To create equal-column grids, responsive galleries and dashboard layouts using CSS Grid.

## 2. Topics Covered
- CSS Grid
- `display: grid`
- `grid-template-columns`
- Fractional units (`fr`)
- `gap`
- `repeat()`
- `auto-fill`
- `minmax()`
- `grid-template-areas`
- `grid-area`

## 3. Tasks Performed

### Task 1: Basic Grid
**File:** `program/grid-first.html`
- Created six boxes numbered 1 to 6.
- Used three equal columns with `1fr` units.
- Added a 12px gap between boxes.

### Task 2: Responsive Gallery
**File:** `program/gallery.html`
- Created a Club Photo Gallery heading.
- Added six photo boxes.
- Used `repeat(auto-fill, minmax(150px, 1fr))`.
- Used a 10px gap to create a responsive layout.

### Task 3: Dashboard Layout
**File:** `program/dashboard-areas.html`
- Created a two-column grid with 200px and 1fr.
- Used named grid areas.
- Arranged Header, Sidebar, Main Area and Footer.
